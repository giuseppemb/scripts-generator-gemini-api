# Gemini script generator

This short Python script generates code from a prompt you write and saves it as a .py file in a folder.
See Gemini API Documentation: https://aistudio.google.com/docs

## Getting Started

1. Install the Gemini library:

   ```bash
   pip install google-genai
   ```

2. Set your API key as an environment variable:

3. Run it, for instance:

   python automation.py "Write a snake game" snake

Finished :)
